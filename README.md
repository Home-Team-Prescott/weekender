# The Weekly Weekender

The public web edition of Home Team Prescott's weekly newsletter, so an issue can be shared on social without anyone needing to be a subscriber.

**Live at:** https://home-team-prescott.github.io/weekender/

## What this is, and is not

`index.html` is the current issue. It is **generated**, not hand-edited — the source lives in the private vault at `Agent-OS/07-Marketing/Weekly-Weekender/`, and this repo only ever holds the published copy.

The email edition still goes out through Go High Level. This is the same issue with a public address, not a replacement for it.

## Voting

The four vote buttons point at the confirmation page rather than at the main website, which is the same place the email edition's trigger links land. One recorder for both audiences, so a vote counts the same whether someone got the newsletter or found it on Instagram.

Voting is open to anybody. No subscription, no sign-in, nothing typed.

## Updating

Do not edit `index.html` here. Rebuild from the vault and push, so the web edition can never drift from what actually went out by email.
